# programs

All FAUST programs of the module. `../firmware` builds them into one
firmware for rev2 (encoder to choose), `../single` builds one of them alone
(rev1, or to try a program). Parameters bind to the hardware by their label
metadata (`[hw:..]`, `[rev1:..]`, `[rev2:..]`, `[cv:..]`, see
`../lib/nemesis/src/nemesis_program.cpp`); on rev2 the parameters without a
knob are settings (turn the encoder). Programs that follow the tempo use the
system transport with `import("nemesis.lib");` (`../faust/nemesis.lib`).
Each program's controls, modes and background are in `docs/<name>.md`
([docs/](docs/)); the `.dsp` keeps its `declare` lines and a pointer there.

Home screen: by default the program's name is shown big. `declare home
"A|B";` shows up to three values big instead (the name moves to the top
line): labels of bargraphs, knobs or settings, or `@tempo` / `@beat`
(the transport's BPM and bar.beat.sixteenth). One value takes the whole
area, two or three get columns with a caption (name and unit). A
`[digits:N]` label option sets the decimals shown (e.g. a pitch ratio
1.015). Used by primetime (A|B), breaker (@beat|@tempo) and harmonizer
(ratio|function); juno shows its patch ([home:1] setting).
